# export
## A lightweight Windows command-line tool for creating custom command aliases to launch programs by name.

### How to use?
- Download export and add it to the environment variables
- Test it: 
```bash
export --version
```
- Or:
```bash
export --help
```
- Run it:
```bash
export <name> "<executable path>"
```
